# Level 8: Q-Learning with Gymnasium: FrozenLake

This level combines the Gymnasium interaction loop from Level 7 with tabular Q-learning. The agent learns action values for deterministic `FrozenLake-v1`, explores with an epsilon-greedy behavior policy, and is evaluated using the learned greedy policy.

## Learning objectives

- Build a Q-table from Gymnasium's discrete spaces.
- Integrate epsilon-greedy action selection with `env.step()`.
- Apply one-step Q-learning after every transition.
- Handle terminal and time-limit endings correctly.
- Separate training behavior from read-only evaluation.
- Interpret success rate and episode length.

## Environment

The notebook uses

```python
env = gym.make("FrozenLake-v1", is_slippery=False)
```

The observation space contains 16 tiles and the action space contains four actions:

| Action | Direction |
| ---: | --- |
| `0` | Left |
| `1` | Down |
| `2` | Right |
| `3` | Up |

The goal gives reward `1`; all other transitions give `0`. Entering either a hole or the goal sets `terminated=True`. The deterministic map has multiple shortest safe routes from the start to the goal, each requiring six actions.

## Q-table

Gymnasium provides the table dimensions:

```python
NUM_STATES = env.observation_space.n   # 16
NUM_ACTIONS = env.action_space.n       # 4
```

The table is initialized as

$$
Q_0(s,a)=0
$$

for all $16\times4$ state–action pairs.

## Epsilon-greedy behavior policy

During training,

$$
A_t=
\begin{cases}
\text{a random Gymnasium action}, & \text{with probability }\varepsilon,\\
\arg\max_a Q(S_t,a), & \text{with probability }1-\varepsilon.
\end{cases}
$$

The implementation uses $\varepsilon=0.1$. When every action value in a state is equal, the greedy helper breaks the tie randomly. Otherwise, `np.argmax` selects the largest entry.

## Q-learning update

For a nonterminal transition, the target is

$$
y_t=R_{t+1}+\gamma\max_{a'}Q(S_{t+1},a').
$$

For a true terminal transition, there is no future value:

$$
y_t=R_{t+1}.
$$

The TD error and update are

$$
\delta_t=y_t-Q(S_t,A_t),
$$

$$
Q(S_t,A_t)\leftarrow Q(S_t,A_t)+\alpha\delta_t.
$$

The hyperparameters are:

| Parameter | Value |
| --- | ---: |
| Training episodes | `5000` |
| Learning rate $\alpha$ | `0.1` |
| Discount factor $\gamma$ | `0.9` |
| Exploration rate $\varepsilon$ | `0.1` |

Q-learning is off-policy because actions are generated by the epsilon-greedy behavior policy, while the target uses the greedy value $\max_{a'}Q(S_{t+1},a')$.

## Termination versus truncation

The update receives `terminated`, not `terminated or truncated`. Consequently:

- true terminal states do not bootstrap;
- a time-limit truncation can still bootstrap from the next observation.

The interaction loop ends on either condition:

$$
\text{done}=\text{terminated}\lor\text{truncated}.
$$

This preserves the distinction between an MDP terminal state and an external time limit.

## Training and evaluation flow

For each training step:

1. select an action epsilon-greedily;
2. execute it with `env.step(action)`;
3. calculate the Q-learning target and TD error;
4. update one Q-table entry;
5. continue from the next observation until the episode ends.

Evaluation uses `greedy_action()` for 100 episodes and performs no Q-learning updates. The notebook copies the table before evaluation and verifies

```python
assert np.allclose(Q, Q_before)
```

## Implementation map

| Function | Purpose |
| --- | --- |
| `greedy_action(observation, Q)` | Selects a highest-valued action and handles an all-equal row randomly. |
| `choose_action(...)` | Implements epsilon-greedy exploration. |
| `q_learning_update(...)` | Computes the target, TD error, and table update. |
| `run_training_episode(...)` | Learns online for one Gymnasium episode. |
| `evaluate_policy(...)` | Measures the greedy policy without modifying `Q`. |

## Expected learned values

A shortest successful path contains six actions. Since reward `1` is received on the final transition, the start-state value of an optimal first action approaches

$$
\gamma^5=0.9^5=0.59049.
$$

The saved notebook output learned this value, achieved a greedy evaluation success rate of `1.0`, and completed every evaluation episode in six steps. Average training performance was lower because it included both early learning and continued exploration with $\varepsilon=0.1$.

Exact training histories can vary because no explicit random seed is set.

## Scope

This is a tabular solution for a small discrete, deterministic environment. It uses a fixed exploration rate and does not use epsilon decay, a neural network, experience replay, or a target network.

## Main takeaway

The custom Q-learning mechanics from Level 5 now operate through a standard environment interface:

$$
\text{Gymnasium transition}\rightarrow\text{TD target}\rightarrow\text{Q-table update}\rightarrow\text{greedy policy}.
$$
